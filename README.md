# GestCom — Gestão de Produção e Fluxo de Caixa

Aplicação web desenvolvida para o controle operacional e financeiro da produção de salgados e empadas. O sistema centraliza o cálculo de fornadas e o acompanhamento de fluxo de caixa em uma única interface, reduzindo erros manuais no dia a dia da produção.

## Funcionalidades
- **Cálculo de Fornada:** dimensionamento da produção de empadas e salgados, facilitando o controle de rendimento e insumos por lote.
- **Fluxo de Caixa:** registro e acompanhamento de entradas, saídas e saldo para controle financeiro da operação.
- **Gestão de Produção:** organização prática dos itens produzidos para apoiar a rotina de vendas e reposição.

## Stack utilizada
- TypeScript, React, CSS.
- Persistência de dados: Supabase, PostgreSQL
- Hospedagem: Vercel
